# Guia Seguro

Site com orientações de segurança digital em linguagem simples, para qualquer pessoa que usa celular e computador.

## Descrição

Projeto de extensão universitária vinculado ao Programa Institucional Inovação, Ciência e Transformação Digital, alinhado à ODS 9 (meta 9.c, na redação adotada pelo Brasil). Nasceu com professores como primeiro público e é aberto a qualquer pessoa.

## Tecnologias

- Next.js 16.4.6 (App Router)
- TypeScript 5
- Tailwind CSS 4.3.3

## Getting Started

```bash
npm install
npm run dev
```

Todos os textos ficam na pasta `content/`.
